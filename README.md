# Pizza Sales Dashboard

An interactive Power BI dashboard for analyzing pizza sales performance, revenue distribution, product categories, and ordering trends.

## Project overview

This project turns raw pizza-sales data into a clear business dashboard. It is designed to help users understand overall performance, identify strong and weak product categories, and recognize useful sales patterns.

## Business questions

- How much total revenue did the business generate?
- Which pizza categories contribute the largest share of revenue?
- Which pizzas are the best and worst performers?
- How do orders and revenue change over time?
- What patterns can support menu and sales decisions?

## Dashboard features

- Key performance indicators for sales and orders
- Revenue contribution by pizza category
- Best- and worst-selling pizza analysis
- Time-based sales trends
- Interactive filters for exploring the data

## Tools and skills demonstrated

- Power BI
- Power Query for data preparation
- DAX measures and calculated metrics
- Data modeling
- Interactive dashboard design
- Business-focused data storytelling

## How to view the dashboard

1. Download the `.pbix` file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Use the dashboard filters and visuals to explore the results.

> GitHub cannot display an interactive `.pbix` dashboard directly. A screenshot or PDF preview can be viewed on GitHub, while the `.pbix` file must be opened in Power BI Desktop.
